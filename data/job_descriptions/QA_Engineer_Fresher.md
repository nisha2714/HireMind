# QA Engineer (Fresher)

**Level:** Fresher

## About the role
Ensure release quality through manual and automated testing of web applications.

## Responsibilities
- Design and execute test cases from requirements
- Report defects with clear steps to reproduce
- Automate regression tests with Selenium
- Take part in release testing and triage

## Requirements
- Understanding of the testing life cycle and test design techniques
- Knowledge of defect life cycle, severity and priority
- Basic Selenium or similar automation
- Attention to detail and clear communication

## Nice to have
- API testing with Postman
- Basic SQL for data validation
