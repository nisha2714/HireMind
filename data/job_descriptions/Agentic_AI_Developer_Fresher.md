# Agentic AI Developer (Fresher)

**Level:** Fresher

## About the role
Build LLM-powered agents and retrieval pipelines that use tools to complete tasks reliably.

## Responsibilities
- Build prompts and tool-calling flows with LLM APIs
- Implement retrieval-augmented generation (RAG) pipelines
- Evaluate agent behaviour and reduce hallucinations
- Log and monitor token usage and cost

## Requirements
- Python programming
- Understanding of LLMs, prompting and structured outputs
- Awareness of embeddings and vector search
- Interest in AI safety, including prompt injection

## Nice to have
- A personal agent or RAG project
- Familiarity with LangChain or similar frameworks
