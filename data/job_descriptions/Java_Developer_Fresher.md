# Java Developer (Fresher)

**Level:** Fresher

## About the role
Join the backend team as a junior Java developer building and maintaining REST services under mentorship.

## Responsibilities
- Implement features in Java and Spring Boot services
- Write SQL queries and JDBC/Hibernate data access code
- Write unit tests and fix defects found in code review
- Follow team coding standards and use Git daily

## Requirements
- B.Tech/BE in Computer Science or related field
- Strong Java fundamentals: OOP, collections, exceptions
- Basic SQL and relational databases
- Understanding of data structures and algorithms

## Nice to have
- Spring Boot or Hibernate project experience
- Familiarity with Maven and JUnit
