# Senior Full Stack Engineer

**Level:** Senior

## About the role
Deliver end-to-end features across a React front end and Node/Python back end.

## Responsibilities
- Architect front-end state management and data fetching
- Design API contracts between front end and back end
- Improve performance, accessibility and Core Web Vitals
- Collaborate with design and product on scope and trade-offs

## Requirements
- 5+ years of full stack development
- Expert React and TypeScript; Node.js or Python on the server
- Relational database design and migrations
- Authentication, authorization and web security (XSS, CSRF)

## Nice to have
- Server-side rendering experience
- CI/CD and cloud deployment experience
