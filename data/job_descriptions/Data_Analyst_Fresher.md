# Data Analyst (Fresher)

**Level:** Fresher

## About the role
Support business teams by cleaning data, running analyses and building dashboards.

## Responsibilities
- Query and join data using SQL
- Clean and analyse datasets with Python (Pandas) or Excel
- Build dashboards and charts that communicate trends
- Present findings to non-technical stakeholders

## Requirements
- Strong SQL: joins, aggregations, subqueries
- Python with Pandas or equivalent
- Basic statistics: distributions, correlation, hypothesis testing
- Clear written and verbal communication

## Nice to have
- Tableau or Power BI project
- Exposure to A/B testing
