# DevOps Engineer (Senior)

**Level:** Senior

## About the role
Build and run the delivery platform: CI/CD, Kubernetes and infrastructure as code.

## Responsibilities
- Design CI/CD pipelines for containerised services
- Operate Kubernetes clusters, scaling and self-healing workloads
- Manage infrastructure as code with Terraform
- Define SLOs, alerting and incident reviews

## Requirements
- 5+ years in DevOps or SRE
- Strong Kubernetes and Docker experience
- Terraform or equivalent IaC
- Security practices: secrets management, least privilege

## Nice to have
- GitOps tooling such as ArgoCD
- FinOps / cloud cost optimisation
