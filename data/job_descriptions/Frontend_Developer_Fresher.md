# Frontend Developer (Fresher)

**Level:** Fresher

## About the role
Build responsive, accessible user interfaces with React as part of the web product team.

## Responsibilities
- Build UI components in React and JavaScript
- Turn designs into responsive layouts with HTML and CSS
- Consume REST APIs and handle loading and error states
- Debug browser issues using DevTools

## Requirements
- Solid JavaScript (ES6+), HTML5, CSS3
- Working knowledge of React: props, state, hooks
- Understanding of responsive design and accessibility basics
- Version control with Git

## Nice to have
- TypeScript exposure
- Experience with a component library or testing with Jest
